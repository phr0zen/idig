Limitación del Desarrollador

Si el Programa se conoce como "Para Desarrolladores", el Licenciatario solo puede utilizar el Programa como parte del desarrollo interno y de las pruebas unitarias del Licenciatario en una máquina de desarrollo. Una máquina de desarrollo es un entorno de escritorio virtual o físico que ejecuta un sistema operativo principal y el Programa, siendo ambos accesibles y utilizables sólo por un desarrollador especificado.

Instalación Ilimitada

Una Instalación Ilimitada es una unidad de medida por la que se puede licenciar el Programa. Una Instalación es una copia instalada del Programa en un disco físico o virtual que se pone a disposición para ejecutarse en un sistema. Una autorización permite Instalaciones ilimitadas del Programa.
